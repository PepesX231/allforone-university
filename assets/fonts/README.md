# Local typography

Noto Sans Thai variable font from Google Fonts, licensed under SIL Open Font License 1.1. The full license and copyright notice are in OFL-NotoSansThai.txt.

Source: https://github.com/google/fonts/tree/main/ofl/notosansthai
Retrieved: 16 October 2026.

Used for Thai body text and headings to keep offline previews consistent. The decorative English logo font remains separate. Existing SVG icons are reused for consistent rendering; no new emoji dependency was added.
